They replace the prototype's system stacks (Iowan/Palatino, Segoe Print, Arial Narrow, SFMono, Arial) with close open equivalents.

## Storage

`data/<id>.ts` holds each TTF as a base64 string, generated by `node scripts/vendor-fonts.mjs`. Modules instead of `.ttf` files mean the renderer needs no `fetch` or file system in the browser or Node, and bundlers split each font into its own lazily loaded chunk. `loadFont` decodes the bytes and checks size and SHA-256 against `fonts.json` before every embed, so an edited module fails with `FONT_INTEGRITY`.

To add or change a font, edit `fonts.json` (clear `sha256` for a new entry), run `node scripts/vendor-fonts.mjs --pin`, review the digests, update this table and bump `RENDERER_VERSION`. Without `--pin` the script downloads again and fails on any digest change. `--from <dir>` reads a local google/fonts checkout instead of downloading.
